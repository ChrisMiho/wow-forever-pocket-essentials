# 0.19.0 Square Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Map look" row whose "Square, bigger" choice gives a 200-across square map with the place name, clock and coordinates inside it; "Round" is today's screen, unchanged.

**Architecture:** The plan's numbers (`Plan` in `ControllerLayout.lua`) learn a second map shape chosen by `opts.mapLook`. A new file, `MapLook.lua` (`PE.MapLook`), owns everything drawn or changed on the map for the square (mask, edge, words, the hidden strip) and is called from the two places that place and restore the ring today. `QuestIcons.lua` asks the layout for the shape when it refreshes its pin list.

**Tech Stack:** Lua 5.1 (LuaJIT offline), the WoW "Forever" client API (Interface 16001), the repo's offline harness under `tests/`.

**Spec:** `docs/superpowers/specs/2026-11-25-0.19.0-square-map.md`

## Global Constraints

- Blizzard's source: `~/.cache/wow-ui-source/forever` at `c01a87b`. Verify every new game call there and cite file and line in a comment beside it.
- No call into a function Blizzard wrote in Lua that writes a field or a global; no field assigned on a game frame. `tests/taint/audit.lua` must pass with no new listed call.
- Never call `SetScale`, `SetPoint`, `ClearAllPoints`, `SetShown` or `Hide` on an Edit Mode system frame (`MinimapCluster` is one; `Minimap`, `ZoneTextButton`, `PlayerCoords` are not).
- `ControllerLayout.lua` has 187 of Lua's 200 top-level locals: add no new top-level local there; new code goes in `MapLook.lua` or inside existing tables.
- Event handlers and callbacks go through `PE:Safe` or `PE:Wrap`; game changes out of a fight only, through `PE:RunOutOfCombat`; every game call through `pcall`.
- Nothing ticks or listens while `mapLook` is 0 or the layout is off.
- `opts.mapLook` defaults to 0 (Round). With 0, every number, rectangle, log line and written layout is byte-for-byte what 0.18.0 gives (existing tests stay untouched and green).
- Comments pass `scripts/check.sh`'s wording check; plain language in every string the player sees.
- Stage files by name; never `git stash`, `git add -A` or reset. Do not push.
- `scripts/check.sh` and `scripts/test.sh` exit 0 before every commit.

## Review Focus

- A saved layout from 0.18.0 with no `mapLook` key: treated as Round, nothing rewritten, no reload asked for.
- The game redraws the map (`UpdateMinimapConfig`) in a fight: the mask is given again once the fight ends, not during it, and only once.
- Switching Square to Round without a reload in between (the reload prompt dismissed): the mask, strip and words follow the option at once; the size follows after the reload; no half state survives a later placement.
- A place name longer than the map (for example "The Temple of Atal'Hakkar"): cut with "...", never wider than the edge box.
- `Minimap`, `MinimapCluster.ZoneTextButton` or `PlayerCoords` missing or renamed: one `SayMissing`-style log line each, no error, the rest still placed.

### Task 2: `MapLook.lua`

**Files:**
- Create: `addons/PocketEssentials/MapLook.lua`, `tests/features/maplook_test.lua`

**Interfaces:**
- Consumes: `Plan.MapLook`, `Plan.MapBox` (Task 1).
- Produces: `PE.MapLook:Place(opts)` (idempotent; called from `PlaceRing` after the ring is hidden, also after the redraw hook), `PE.MapLook:Restore()` (from `RestoreRing`), `PE.MapLook:IsSquare() -> boolean` (true only while the square mask is on the map and was not refused), `PE.MapLook:SnapshotPieces() -> { { name, frame } }`.

- [ ] **Step 1: Failing tests** in `maplook_test.lua` against the stand-in:
  - `Place({ mapLook = 1 })` calls `Minimap:SetMaskTexture` once with `"Interface\\Buttons\\WHITE8X8"`; a second `Place` with nothing changed calls it again only when told it is a redraw.
  - `Restore()` calls it with `"ui-hud-minimap-frame-generic-mask"`, shows the strip if it was shown before, hides our edge and words, stops the clock and the coordinates updates (no `OnUpdate` script and no registered event left on our frames).
  - `SetMaskTexture` raising: `IsSquare()` is false, the debug log holds `map look: the square mask was refused` exactly once over three `Place` calls, the round disc is what `PlaceRing` draws.
  - In a fight (`InCombatLockdown` true) `Place` changes nothing on game frames and runs once after the fight.
  - The place name: text from the game's call, cut with "..." so the string's width (the stand-in's `GetStringWidth`) is at most 190.
  - `Place({ mapLook = 0 })` after a Square placement equals `Restore()` for the mask, strip and words.
  - Missing `Minimap`, missing `ZoneTextButton`, missing `PlayerCoords`: no error, one log line each.
- [ ] **Step 2:** tests fail.
- [ ] **Step 3: Implement** per the spec's "The edge", "The words inside the map", "Off, and failing safely" and "Logging".
