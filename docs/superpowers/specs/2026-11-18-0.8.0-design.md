# 0.8.0: Move instead of presets, Bags in two, button themes, touch question

The owner asked on 2026-11-18, after testing 0.7.0: "do the next 3, and call
the release 0.8.0", meaning the three "Later builds" of
`2026-11-18-number-control-design.md`. Plus, from the same message and the
answers that followed:

- **Merge nearby icons** is confusing. The owner picked "show it as a
  distance".
- **Setup guide, first page:** the d-pad lands on Close or Skip; it should
  go to Start first.
- **Setup guide, first page:** ask whether the player uses the touch
  screen. If not, turn off the Sort button and the Up and Down buttons (the
  owner ticked exactly these two).
- **Up and Down look "really ugly".** The owner picked mockup B: a scroll
  bar with arrows.
- **Button colours:** "one horde and one alliance theme for now".

This spec is approved by that instruction and those answers. The calls
marked **(builder's call)** were made by Claude and are reported to the
owner with the build.

## 1. Move replaces the position buttons

- **Quest arrow:** the "Arrow position" row goes. In its place is one
  button, **Move the arrow**, which opens the Move window with the arrow
  already picked.
- **Round button:** the "Round button position" row goes. In its place
  (Pocket Essentials section of the settings) is **Move the round button**.
- **Nothing jumps.** The saved preset (`questArrow.position`, `ui.hubPos`)
  stays the piece's starting point, and the saved Move offset is added to
  it as today. No preset is converted.
- **Reset** in the Move window puts the picked piece back where everyone
  starts:
  - it clears the offset, as today;
  - it also sets the preset back to the default (arrow `top`, round button
    `LEFT`).
- **New label (builder's call):** "Move things" is renamed **Move on
  screen**, in the window title, the settings' bottom row, the setup guide
  text and chat messages.
- **Opening with a piece picked:** `PE.Move:Open(key)` takes an optional
  piece key. With one it picks that piece; without one, it picks as
  today.
- **The other pieces** (chat prompt and any others registered) are
  unchanged.

## 2. Bags split in two

**Two features:**

- **Bag window** (new): **Bag size** (Normal / Large / Extra large) and the
  **Bag icons** toggle.
  - The feature's description **(builder's call)**: "Makes the bag window
    bigger and tidier."
- **Bag sorter:** two toggles, side by side:
  - **Sort button: On / Off** (saved `showTab`);
  - **Sort stick: Left / Right** (saved `sortKey`, `l3` / `r3`).

**Gone:** "How to sort" and "D-pad to Sort".

- **D-pad to Sort** is now on whenever the Sort button shows, and off when
  it does not. The owner tested it in 0.6.0 and it works.
- **The stick press** always sorts, with the chosen stick. "Button only"
  no longer exists. A saved `sortKey = "none"` becomes `l3` at load.

**Each feature works on its own:**

- **Bag window alone:** size and icons, with no Sort tab and no stick.
- **Bag sorter alone:** the Sort tab and stick, at Blizzard's size, icons
  in the grid.

Both live in `Bags.lua` and share its engine and its taint rules
(header comment). No new game calls.

**Saved data:**

- **Bag window's options** are `size` and `iconRow` in its own options
  table.
- **The first time 0.8.0 loads** (Bag window has never been saved):
  - Bag window is switched on exactly when Bag sorter was on;
  - `size` and `iconRow` are copied from Bag sorter's saved options.
- **A fresh install** has both off.
- **Old keys:** Bag sorter's old `size`, `iconRow` and `dpad` keys are left
  in the file and no longer read.

## 3. Round button themes

- **New row** in the Pocket Essentials section: **Button colour: Gold /
  Horde / Alliance**, saved as `ui.hubColor`. The default is `gold`, which
  is today's look; an unknown value is drawn as gold.
- **Colours (builder's call):**

  | Theme | Ring and label | Fill | Pressed |
  |---|---|---|---|
  | **Gold** | as today | as today | as today |
  | **Horde** | red (0.85, 0.15, 0.10) | dark red (0.18, 0.03, 0.03) | (0.45, 0.07, 0.05) |
  | **Alliance** | light blue (0.35, 0.62, 1.00) | dark blue (0.03, 0.08, 0.24) | (0.10, 0.25, 0.55) |

- **Colours only.** No faction emblems or Blizzard art.
- **Applies at once.** A theme change repaints the round button, with no
  reload.

## 4. Merge nearby icons as a distance

- **Heading:** **Merge icons closer than**.
- **Values:** the box shows `N%`, with the unit word **of map**. 0 shows
  **Off**.
- **Unchanged:** the range (0 to 10) and the saved values.
- **New field:** number rows get an optional `suffix` (here `"%"`), added
  after the number but not after Off or All.

## 5. Setup guide, first page

- **D-pad start:** when the first page opens, the controller highlight
  starts on **Start**, not on Close or Skip.
- **The touch question:** the Welcome page has one row, **Do you use the
  touch screen?** with **Yes** and **No**.
  - It is saved as `ui.touch`. Out of the box (nil) it reads as Yes.
- **No**, at the moment it is pressed:
  - sets `ui.touch = false`;
  - turns Bag sorter's Sort button off (`showTab = false`).
- **Yes**, at the moment it is pressed:
  - sets `ui.touch = true`;
  - turns the Sort button back on only if the No press in this guide had
    turned it off **(builder's call)**.
- **While `ui.touch` is false**, Up and Down (the scroll bar, section 6)
  are not shown in the settings, the setup guide or the chat picker. The
  list takes the whole width, and the d-pad keeps scrolling to whatever it
  lands on.
- **In the settings (builder's call):** the same choice is a toggle in the
  Pocket Essentials section, **Touch screen: Yes / No**, so it can be
  changed later. Changing it there only shows or hides the scroll bar; it
  does not touch the Sort button.

## 6. The scroll bar (mockup B)

Replaces the two tall Up and Down buttons of every scroll area
(`UI:CreateScrollArea`: settings, setup guide, chat picker).

- **Size:** a slim column at the right, about `M.button * 0.75` wide.
- **Arrows:** an up arrow tab at the top and a down arrow tab at the
  bottom, each `M.button` tall.
  - They use the number box's ends' look: gold edge, gold arrow, dimmed at
    the end of the list.
  - They page exactly as Up and Down do today, and stay d-pad stops where
    Up and Down were.
- **Track:** between the tabs, a dark track with a gold marker.
  - The marker's height is the share of the list in view, and its place is
    the scroll position.
  - Tapping the track above the marker pages up; below it pages down.
  - The track is not a d-pad stop.
- **The arrow shape** is a game texture verified in `Gethe/wow-ui-source`,
  branch `forever`, or, failing that, a text glyph that the game's font
  draws.
- **When it shows:** only when the list does not fit, as today, and only
  while `ui.touch ~= false`.

## Not changing

- **Saved data:** every saved value other than those named above.
- **Commands:** `/qd` and `/pe`.
- **Behaviour:** the Move window's arrows and their behaviour.

## Device test

- **Move:**
  - "Move the arrow" and "Move the round button" open Move on screen with
    that piece picked.
  - Reset sends it to the default spot.
  - A moved piece stays put after a reload.
- **Bags:**
  - Bag window and Bag sorter each work alone and together.
  - The Sort button and Sort stick toggles work, and the d-pad reaches
    Sort when the button shows.
- **Button colour:** each theme repaints the round button at once.
- **Merge:** reads "Merge icons closer than 3%", with "of map" under it.
- **Setup guide, first page:**
  - the highlight starts on Start;
  - No hides the scroll bar and the Sort button, and Yes brings back the
    scroll bar.
- **Scroll bar:** the arrows page, the marker follows the list, and a tap
  on the track pages.
