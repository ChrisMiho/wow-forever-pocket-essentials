# 0.9.0: UI redesign from the mockups

**Status:** approved by the owner on 2026-11-20 ("I am so happy with this setup... implement these enhancements to the ui ... until the ui looks exactly like the mockups, then release another build").

**Visual source of truth:** `docs/ui-review/mockup-0.8.1.html`, "Proposed" version, at 720p. The page's script builds everything from the same numbers as `UI.lua`, so the sizes below are 720p units at Medium and come from that code. Look first at the `/* ===== PROPOSED ===== */` section. The owner's notes are in `docs/ui-review/2026-11-20-feedback-round-1.md` (rounds 1–4).

**Goals (owner):** match the mockups, keep what each helper does as the PRD says, and stay simple and lightweight for the handheld. Nothing ticks while its feature is off, and features still default off.

## Shared rules (UI.lua)

`M` below is `UI:Metrics()` (button 56, row 66, gap 10, pad 14, font 25, small 20, border 2 at Medium).

| Name | Colour |
|---|---|
| Card fill | (.085, .085, .10) |
| Card divider | (.22, .22, .25), height `border*0.5`, minimum 1 |
| Selected fill | (.56, .42, .03), with a gold (1, .82, 0) bar `max(3, border*1.5)` tall along the bottom of the selected segment |
| Gold-brown edge | (.62, .52, .22) |
| Window fill | (.05, .05, .07) |

**Text colours:** row names (.92, .92, .92) in the `font` kind. Help lines use the small font in dim (.62, .62, .62). Headings in cards use the small font in gold.

**Widgets.** All are one `M.button` tall and safe to rebuild through pools, like today. Each pressable part is a d-pad stop, shows the cyan focus ring, and has the press flash.
1. **Switch** (2×button wide).
   - On: green style, with a light knob (.9, 1, .92) on the right and "On" on the left.
   - Off: grey style, with a knob (.62, .62, .64) on the left and "Off" on the right.
   - The knob is square: side = `button − 4*border − gap*0.4`, inset `2*border + gap*0.2`.
   - The words are in the small font.
   - Blocked: disabled style, and a tap does nothing. Failed: warn style, reading "Problem".
2. **Segmented choice** (control width, see below). An outer edge in the normal border colour, then n equal segments separated by one border.
   - Unselected: normal fill, text (.82, .82, .82).
   - Selected: selected fill, white text, and the gold bottom bar.
   - Every segment is a d-pad stop; Left and Right move between segments.
3. **Number** (control width). Ends of button×button using the step / stepDim styles. The well fills the rest: gold-brown edge, fill (.03, .03, .04), value in gold `font`, unit word in dim `small` under it when it fits (the same rule as today's NumberBox).
4. **Action button** (control width), normal style. Its text is the action itself ("Open", "Move the arrow", "Reload").
5. **Row:**
   - The name is on the left, in a column `innerWidth − controlWidth − gap` wide. An optional help line sits under it.
   - The control is on the right.
   - `controlWidth = min(innerWidth*0.58, button*9)`.
   - Row height = `max(button, name + help)`. Both the name and the control are centred vertically in the row.
   - Rows are separated by `gap`.
6. **Card:** card fill from x to x+w, with `pad` inside on every side. Cards are separated by `gap`.
7. **Feature card:**
   - Name (`font`, white), then `gap*0.2`, then the one-line description (`small`, grey).
   - In the setup guide only, an optional "How: " line in the small font, gold prefix then grey text.
   - Then any blocked or failed line (amber), as today.
   - The switch sits on the right, centred on this header.
   - When the feature is on, a card divider and then its option rows. Rows marked `always` also show while it is off.
   - When it is off and it has options: the dim small line "Switch it on to choose how it works."
8. **Scroll area:** the bar shows only when the content is taller than the view, using the two-pass rule Setup.lua uses today. The bar itself is unchanged.

**The option-row interface** that feature files declare. It extends today's `options` lists; Settings and Setup draw them.
- Choices rows (toggle or not) are drawn as segmented controls. The `toggle` flag stops mattering for drawing; keep it for old saved values.
- `help = "text"`: the optional grey line under the row name.
- `number.step` (default 1): the step size of the − and + ends.
- Action rows: `label` is the row name and `button` is the button text. When `button` is missing, use "Open".
- Rows show in list order.

## Settings window (Settings.lua)

The window keeps today's size: `min(screenW*0.96, Px(1180))` × `screenH*0.92`. The title is "Pocket Essentials" and Close stays where it is.

**Tabs** sit on the left of the content, `5*button` wide (280).
- Tab height = `min(button, (contentHeight − 7*border) / 8)`, stacked with one border between tabs.
- Unselected: card fill, text (.88, .88, .88) in `font`, left-aligned with `pad` inset.
- Selected: selected fill, white text, and a gold bar `max(4, border*2)` wide on its left edge.
- **Dot:** a feature tab has a dot of diameter `small*0.55`, `pad` from its right edge. Green (.35, .92, .45) when any of its helpers is on, grey (.40, .40, .43) otherwise.
- **Errors tab:** when there are errors, a red round badge (.85, .08, .08) with the count in white `small`, diameter `small*1.3`.

| Tab | Holds |
|---|---|
| Quest icons | questIcons |
| Quest arrow | questArrow |
| Bags | bagWindow, then bags |
| Vendors | sellJunk, then repair |
| Chat | chat |
| Menu background | a heading card, then menuBg |
| General | the core settings |
| Errors | the debug log and the error list |

**The page** is to the right of the tabs: x = tabs + gap, width = the rest. It is a scroll area holding the selected tab's cards. Only the selected tab is built.

**Menu background heading card:**
- "Fixes for the game's own interface" in gold `font`.
- Then, in the small font, grey: "Parts of the default Blizzard UI that are hard to use on a handheld, or that low graphics hide."

**General** is two cards.
- Card 1:
  - **Button size:** Small / Medium / Large.
  - **Round button colour:** Gold / Horde / Alliance.
  - **I play with:** Touch controls / Controller. It saves `ui.touch` true or false. Controller also sets Bag sorting's `showTab` to false; Touch controls sets it back to true.
- Card 2:
  - **Move things on screen** [Open]: opens Move on screen.
  - **Setup guide** [Open].
  - **Reload the interface** [Reload]: calls `PE:ReloadNow()` straight from the tap.

**Errors** is two cards.
- Card 1:
  - Header: "Debug log" (`font`, white), the help line "Turn it on, play until the problem happens, then tap Save. Send the file SavedVariables/PocketEssentials.lua.", and "N of 10,000 lines" in blue. The switch is on the right.
  - Divider, then the rows **Save the log (reloads)** [Save] and **Empty the log** [Empty].
- Card 2:
  - "Errors" on the left and **Clear errors** (control width) on the right, disabled style when there are none.
  - Then "No errors recorded." (dim small), or the entries as today: gold head line, white message, dim stack.

**Quest Icon Key** opens from the Quest icons tab ("Icon key" [Open]).
- It replaces the page with a **Back** button (3×button) and a card holding the five key rows: icon button×button, name `font`, description `small`.
- Descriptions:
  - Kill: "A creature to kill."
  - Loot: "A creature that drops a quest item."
  - Use: "An object to click, use or open."
  - Explore: "A place to go to, or someone to talk to."
  - Turn in: "Where to hand the quest in."
- Then the dim line "Tap an icon on the map to see what it is for."

**Header above the page:** the old QuestDots warning and the "Reload now" bar stay as they are today. They sit above the page area, across its width.

**Removed:**
- the fold buttons and `ui.folded`
- the "Tip: press and hold..." line
- the bottom row of buttons
- "Move the round button"

**Controller:**
- Up and Down move within a column (the tabs, or the page).
- Right from a tab goes to the page's first stop.
- Left from the first stop in a page row goes to the selected tab.
- A on a tab selects it.
- B closes, as today.

## Chat window (Chat.lua)

- The "Three-finger tap for the keyboard" hint is **removed**.

- **Layout:** 3 columns of chips, each `3.4*button` wide and `button` tall, with `gap` between them. The window is `2*pad + 3*chip + 2*gap` wide, and as tall as its content: `border + titleBar + gap + content + pad`. It is centred.
- **Contents:**
  - "Talk in" heading (small, gold), then `gap*0.4`, then the target chips. The targets are as today.
  - Then `gap*1.5`, the "Whispers" heading, and the name chips, up to 6.

### 0.9.1 changes (from the 0.9.0 device test)

1. **Controller-agnostic glyphs.** On Welcome, the round A and B are replaced by a face-button diamond: four small circles (top, left, right, bottom) in the same `0.75*button` square, outlined (.70, .70, .72) with a dark fill (.16, .16, .18). The circle that matters is filled light (.85, .85, .87): bottom for "Press the highlighted button", right for "Close the window". No letters. The d-pad cross stays.
2. **D-pad path on every screen.** The first stop is the screen's first control (Welcome: the play-style choice; a feature screen: usually its switch; a screen with no controls: Next). Nothing highlighted, any d-pad press lands there. Down from the last row of controls goes to **Next** (Start / Finish); from Next, Left goes to Skip, then Back; Up from the bottom row goes back to the last row of controls; Down from the bottom row goes round to the first control. Close comes last: Right from Next, or Up from the first control; Up from Close goes to Next. With touch off, a long screen is still paged first. When Next or Back changes the screen while the highlight is in use, the highlight goes to the new screen's first control; on a screen with no controls it stays on Next, so A pressed again and again still walks the guide.
3. **Vendors and menus:** no "How:" line on Menu background; each card keeps only its one-line description.
4. **Round button and chat:** the line is just "The PE button is always on screen.", and the chat card has no "How:" line (its description "Tap the round button to pick who to talk to." says it). The How: lines stay on Quest icons and Quest arrow.
