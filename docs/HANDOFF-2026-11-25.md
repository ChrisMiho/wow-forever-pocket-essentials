## Rules that came out of 2026-11-24 (also in ARCHITECTURE, "Calls into Blizzard's Lua")

- Never call a function Blizzard wrote in Lua that writes a field or a global, and never
  assign a field on a game frame. `FCF_SetWindowAlpha` (it writes `oldAlpha` on the chat
  windows) made the game refuse its own controller actions from login on. Fixed in 0.16.3.
  `tests/taint/audit.lua` now fails on any unlisted call of that kind.
- Edit Mode system frames replace `SetScale`, `SetPoint`, `ClearAllPoints`, `SetShown` and
  `Hide` with Lua (`EditModeSystemTemplates.lua`): never call those on them. `SetAlpha` is
  the engine's.
- A refusal's call stack shows where the game noticed, not who caused it. What found the
  cause was a build with one On/Off row per part and the owner reloading through them.
- `ControllerLayout.lua` is at Lua's limit of 200 top-level locals: new code goes in its own
  file or inside existing tables.
- Verify every game call in `~/.cache/wow-ui-source/forever` and cite file and line.
