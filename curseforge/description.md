# Pocket Essentials

A small, lightweight addon suite that makes WoW Forever comfortable to play on a handheld, with touch and a controller together: big buttons, no tiny targets, no typed commands.

## Early version (0.0.x)

In progress: version 0.0.1 is written but has not run on a device yet. Treat every feature as unproven until it has run in the game. Testers are very welcome, and bug reports help a lot.

## Who it's for

Anyone playing WoW Forever on a handheld, on any device that runs the client.

## Features

Every feature has its own on/off switch and starts switched off.

- **Quest icons:** objective icons on the map and minimap, no blue haze. Tap an icon to pick that quest.
- **Quest arrow:** an arrow to the nearest objective in your zone, with distance.
- **One big bag:** Blizzard's combined bag with a big Sort button; L3 sorts while it is open; three sizes.
- **Sell junk automatically:** sells every grey item at vendors. Only the last 12 sold can be bought back.
- **Repair automatically:** repairs from your own money.
- **Big chat buttons:** the round button opens a picker with one big button per channel and per recent whisperer. A badge shows unanswered whispers.
- **Layout helper (experimental):** one-tap switch to Blizzard's Gamepad layout and back.

## Requires QuestieDB for quest features

The quest icons and quest arrow need the [QuestieDB](https://www.curseforge.com/wow/addons/questiedb) addon. Everything else works without it. Without QuestieDB, the two quest features stay off and the settings window tells you why.

## Opening the settings

- Tap the round "PE" button at the left edge of the screen. If Big chat buttons is on, it opens the chat picker instead.
- Hold the round button for half a second to always open the settings.
- Type `/pe`, or use the addon-list button on the minimap.

## Reporting problems

If something goes wrong, the settings window has an Errors page that shows what failed, in large text. Please report problems and ideas on GitHub: https://github.com/ChrisMiho/wow-forever-pocket-essentials/issues
